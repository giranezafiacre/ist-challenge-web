# IST Approval System - Frontend

This is the **Next.js frontend** for the IST Approval System.  
It provides a user interface to view and create purchase requests, track approval status, and interact with the backend API.

---

## Quick Start

```bash
# Clone the repository
git https://github.com/giranezafiacre/ist-challenge-web.git
cd ist-challenge-web

# Install dependencies
npm install

# Run development server
npm run dev
